# Reference figures

Seven PNGs were copied unchanged from the completed formal analysis:

1. `01_LASSO_cross_validation.png`: training LASSO cross-validation curve.
2. `02_LASSO_coefficient_paths.png`: LASSO coefficient paths.
3. `03_ROC.png`: internal and external ROC curves.
4. `03_Calibration.png`: internal and external calibration curves.
5. `03_DCA.png`: updated DCA, 0%–80% threshold-probability axis, 10.8 × 6.2 inches, 600 dpi.
6. `04_SHAP_importance.png`: exact XGBoost mean absolute SHAP on the internal-validation sample.
7. `04_SHAP_beeswarm.png`: exact XGBoost SHAP summary, raw log-odds scale.

Hashes in `docs/provenance.json` verify the copied originals. Figure generation is retained in the analysis scripts and requires the authorized local analysis inputs. No new figure fitting or statistical result changes were made for this repository release.
